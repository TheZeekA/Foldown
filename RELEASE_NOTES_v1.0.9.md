# Foldown 1.0.9

Released 1 September 2026 by Zeeka Limited.

Foldown 1.0.9 adds clearer visual separation between user and AI messages in Interactive Mode.

## Added

- User chat messages now use a light-blue accent.
- Foldown AI responses now use a light-green accent.

## Verification

- Frontend tests: 55 passed.
- Rust tests: 146 passed.
- Production frontend build passed.
- Windows NSIS installer and standalone executable built successfully.

- `Foldown-1.0.9-Windows-x64-Setup.exe` — Windows installer.
- `Foldown-1.0.9-Windows-x64-Standalone.exe` — portable application executable.
