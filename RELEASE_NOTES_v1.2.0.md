# Foldown v1.2.0

## Major change: Pro licensing

- Added Keygen.sh license-key activation and validation.
- Added License settings with visible license key, active/not-active status, and whole-day expiry display.
- Added license replacement, revalidation, and removal.
- Added a seven-day offline grace period after successful validation.
- Unlocked OpenAI, Anthropic, and Gemini providers for active Pro licenses.
- Local AI remains available without a license.
- Enforced cloud-provider licensing in both the frontend and Rust backend.
- Added signed in-app update checks at launch and from Settings > About > Check for Updates.
- Corrected the README and About version to 1.2.0.
