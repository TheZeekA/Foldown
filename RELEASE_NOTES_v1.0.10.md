# Foldown v1.0.10

## Interactive Mode and navigation layout

- Interactive Mode now shows only the file navigation and AI chat, with the chat filling the available workspace instead of leaving a blank editor area.
- Selecting a file or AI citation closes Interactive Mode and opens the file in the editor.
- The file navigation, AI chat, and split editor/preview columns can be resized.
- The workspace switcher shows the workspace name without the full path and provides a larger list of recent workspaces.

## File tree styling

- Folders have a distinct light-grey background.
- Files use a very light-blue hover highlight, while folders retain their grey background.
