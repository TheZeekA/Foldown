# Foldown 1.0.7

Released 31 August 2026 by Zeeka Limited.

Foldown 1.0.7 improves workspace switching from the sidebar.

## Added

- Clicking the current workspace name opens a recent-workspaces menu.
- Recent workspaces show their full names and paths, with one-click switching.
- Missing recent workspaces remain visible and can be removed from the list.
- Added an **Open another workspace…** action directly to the workspace menu.

## Fixed

- Workspace names are no longer limited to the narrow header space when choosing a workspace; the full name is available in the expanded menu.

## Downloads

- `Foldown-1.0.7-Windows-x64-Setup.exe` — Windows installer.
- `Foldown-1.0.7-Windows-x64-Standalone.exe` — portable application executable.

Foldown requires 64-bit Windows and Microsoft Edge WebView2.
