# Contributing to Foldown

Thanks for helping improve Foldown. Please open an issue before substantial
changes, and keep pull requests focused. Include tests for behaviour changes
where practical.

## Development

Install dependencies with `npm install`, run the frontend tests with `npm test`,
and run Rust tests from `src-tauri` with `cargo test`.

Never commit API keys, license keys, updater signing keys, certificates,
workspace data, generated installers, or local build directories.

By contributing, you agree that your contribution is provided under the
repository's MIT License.
